# 01. Basics

О чем речь: синтаксис JSON, валидные/невалидные файлы.

## Файлы
| Файл                          | Валиден? | Что иллюстрирует                                              |
|-------------------------------|----------|---------------------------------------------------------------|
| `valid.json`                  | +        | Все шесть типов: object, array, string, number, boolean, null |
| `invalid_trailing_comma.json` | -        | Запятая после последней пары - запрешена                      |
| `invalid_single_quotes.json`  | -        | Ключи/строки только в двойных кавычках                        |
| `invalid_nan.json`            | -        | `NaN` не существует в json                                    |

## Как проверить
```bash
python -m pytest 01_basics -q
```

## Нюанс: `NaN` в Python
`invalid_nan.json` содержит `NaN`. **Стандарт JSON** его запрещает, но Python `json.loads` по умолчанию **принимает** `NaN` как расширение. Тест использует `parse_constant`, чтобы отключить это расширение и честно проверить, что файл невалиден **по стандарту***.
